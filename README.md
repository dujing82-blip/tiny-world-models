# Tiny World Models — Experiment B

A beginner-friendly **TensorFlow + Google Colab** mini world model for AI Builders Lab.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/dujing82-blip/tiny-world-models/blob/main/Mini_World_Model_Colab.ipynb)

Run all cells in Colab (CPU is sufficient). The notebook trains a neural network to predict the future position and velocity of a 2D ball from its current state and force, plots real vs imagined trajectories, visualizes error growth, animates motion, and explores alternative actions.

No external datasets or installs required. The system is a simplified state-based learned dynamics model, not a pixel-video generator or a full robotics world model.
